## Interpreting the register

The report count is useful for breadth of patterns, not as a count of distinct implementation techniques: prefix checks, double decoding, symlink following, and archive extraction recur across unrelated projects. Several cases document only a narrow file class, metadata oracle, local-only tool, or conditional chain. A code-review finding must be derived from the current source, configuration, dependency version, and reachable call path, not inferred from a similar product advisory.
