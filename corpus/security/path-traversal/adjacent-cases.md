# Adjacent path-handling cases and leads

These reports are useful when the reviewed Web service calls the affected component, but their primary trigger is not necessarily a remotely reachable Web request. They are **not counted** among the 50 Web/application cases in [the main register](published-cases.md).

| ID | Source | Why it is useful | Scope caveat |
|---|---|---|---|
| PA-01 | Spring AI [CVE-2026-59294](https://spring.io/security/cve-2026-59294/) | A URI fragment was appended verbatim to a cache file name before a write; untrusted tenant/admin/catalog model URIs could produce an arbitrary file write. | The vulnerability is in a backend cache service; Web reachability depends on how the application accepts model/resource URIs. |
| PA-02 | Spring Integration [CVE-2026-40987](https://spring.io/security/cve-2026-40987/) | A remote FTP/SFTP/SMB server supplied a filename that the synchronizer wrote under `localDirectory` without canonicalization. | Trigger is a malicious/compromised remote file server in a synchronization workflow, not necessarily a Web request. |
| PA-03 | Symfony UX Toolkit [CVE-2026-55878](https://github.com/symfony/ux/security/advisories/GHSA-p9xj-fpr2-jf2q) | Recipe manifest `copy-files` paths were accepted because `Path::isRelative()` treats parent-relative paths as relative; reads and writes then escaped the recipe directory. | Local developer/CI command consuming a crafted or compromised kit; relevant to supply-chain and build automation reviews. |
| PA-04 | Appium `@appium/support` [CVE-2026-30973](https://github.com/appium/appium/security/advisories/GHSA-rfx7-4xw3-gh4m) | ZIP extraction created an `Error` object for an escaping member but did not throw it, so an ordinary parent-relative member could be written outside the destination. | Shared extraction library; assess the caller and whether an uploaded archive reaches it. |
| PA-05 | Appium `@appium/support` [CVE-2026-103975](https://github.com/advisories/GHSA-qfxx-c367-67f8) | A follow-up Zip Slip path used an archive symlink to defeat the earlier plain-entry-name fix. | Distinct extraction primitive and patch follow-up; filesystem entry types and extraction order matter. |
| PA-06 | `mholt/archiver` [CVE-2019-10743](https://github.com/advisories/GHSA-h74j-692g-48mq) | Unarchive functions joined archive member names to a destination without preventing traversal. | General-purpose Go archive library; application exposure depends on the caller. |
| PA-07 | `mholt/archiver` [CVE-2025-3445](https://github.com/advisories/GHSA-7vpp-9cxj-q8gv) | Later crafted-ZIP traversal report; useful for reviewing fixes and symlink/member-path handling in the same library family. | Keep distinct from the 2019 report; do not infer the exact exploit condition from the title alone. |
| PA-08 | `decompress` [CVE-2026-10732](https://github.com/advisories/GHSA-h39j-r5qq-r9mm) | A symlink-based archive write bypassed an earlier `preventWritingThroughSymlink` fix. | Library-level ZIP extraction; check the exact package version and archive entry order. |
| PA-09 | Argo Workflows [CVE-2025-62156](https://github.com/advisories/GHSA-p84v-gxvw-73pf) | Workflow tar extraction joined a member path in a way that let absolute paths override the intended base. | Impact depends on workflow configuration and which archive sources are accepted. |
| PA-10 | Vikunja restore [CVE-2026-27819](https://github.com/advisories/GHSA-42wg-38gx-85rh) | Restore-from-ZIP path traversal; use it to inspect archive restore/import helpers. | The cited path is a restore/CLI workflow; Web exposure is not assumed. |
| PA-11 | Twig legacy loader [GHSA-7cvr-xhm5-x998](https://advisories.gitlab.com/composer/twig/twig/GHSA-7cvr-xhm5-x998/) | Historical source gives a narrower example of non-trusted template names escaping a configured filesystem loader directory. | Alias/duplicate of CVE-2022-39261 in [PT-009](published-cases.md); do not count as a second case. |
| PA-12 | Symfony path policy, Windows extended prefix [GHSA-6gmc-424x-xgpm](https://github.com/siyuan-note/siyuan/security/advisories/GHSA-6gmc-424x-xgpm) | A Windows extended-length prefix bypassed a denylist-based sensitive-path check and allowed a read-to-public-assets chain; the advisory also notes a write-side path but labels it out of scope. | Path-policy bypass, not a conventional `..` traversal. Keep separate from the confirmed SiYuan traversal findings. |
| PA-13 | Echo encoded-slash routing [CVE-2026-55677](https://github.com/advisories/GHSA-vfp3-v2gw-7wfq) | Router and static handler decoded `%2F` at different stages, bypassing route-level access control for static files. | Authorization/path-parser mismatch; the report does not require parent-directory traversal. |
| PA-14 | ICEcoder [CVE-2026-64836](https://github.com/advisories/GHSA-wx3p-7qfr-rqrp) | An external, unreviewed GitHub Advisory Database record alleges a broken `realpath()` confinement check and authenticated file read/write/delete. | **Unreviewed lead; not counted** toward the sourced-case threshold. Verify against the vendor or a reviewed fix/advisory before promoting. |

The corpus deliberately excludes unrelated upload weaknesses that do not cause a path escape, as well as desktop-only archive examples without a relevant server or Web-adjacent processing path.
