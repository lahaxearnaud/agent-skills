# Code like me

A portable personal coding profile derived from anonymized analysis of the owner's Git history. It applies as a default when available, while respecting the target repository and current instructions. It includes the owner’s confirmed preferences on pragmatic Symfony services, `final`/`readonly` where appropriate, and branch-level tests. Its examples are synthetic and it needs no access to GitHub or the private research archive at use time.

```sh
npx skills add lahaxearnaud/agent-skills --skill code-like-me --agent codex opencode --global --yes
```

Agent products differ in how installed skills are discovered and triggered; installation alone cannot guarantee automatic invocation. If needed, activate it in the target agent's local instructions without overriding that project's conventions.
